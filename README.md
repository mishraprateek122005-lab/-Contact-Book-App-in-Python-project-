# Contact Book App in Python

## About the Project
The Contact Book App is a Python project that helps users manage their contacts easily. It is designed to practice Python programming and basic data management operations.

## Features
- Add new contacts
- View saved contacts
- Search for contacts
- Update contact details
- Delete contacts
- Exit the application

## Technologies Used
- Python
- Basic Python Programming
- Data Management

## How to Run the Project
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the Python file using the command:

```bash
python main.py
```

Note: Replace `main.py` with your actual Python file name if it is different.
